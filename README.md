# payments-lab

My portfolio for a 32-week payment security engineering plan (see `docs/PLAN.md`).
Claude Code is configured as a tutor here: see `CLAUDE.md` and `.claude/`.

## Commands
| Command | Use |
|---|---|
| `/today` | Start a session: picks today's activity from the weekly rhythm |
| `/learn <topic>` | Worked-example explanation, then a check question |
| `/quiz [topic]` | Socratic quiz, one question at a time |
| `/review [path]` | Senior payments engineer code review (no rewrites) |
| `/verify <what>` | Compare output against published test vectors |
| `/debug <expected vs got>` | Find first divergent intermediate value |
| `/drill [area]` | Production incident role-play |
| `/checkpoint [phase]` | End-of-phase oral exam |
| `/confused <thing>` | Log and untangle a confusion |
| `/progress [done X]` | Status and schedule check |
| `/journal` | Sunday summary review |
